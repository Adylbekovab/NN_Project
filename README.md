# Conceptual Captions - Data Preprocessing Pipeline

This repository contains the data preprocessing pipeline developed for the Conceptual Captions dataset, part of a university software project focused on image captioning. The work involved acquiring, cleaning, filtering, validating images, and analyzing the dataset to prepare it for training a CNN-Transformer model.

## Repository Contents

- **`notebook.ipynb`:** A Jupyter Notebook containing the complete Python code for all preprocessing steps:
  - Loading raw Conceptual Captions TSV data.
  - Merging, filtering, and cleaning text data.
  - Asynchronous image download and validation using `aiohttp` and `PIL`.
  - Final dataset creation (saving local image paths).
  - Textual analysis (caption length, vocabulary size, common words).
- **`README.md`:** This file, providing an overview.
- **`figures/`:** Directory containing visualizations generated by the notebook:
  - `figure_1_dataset_size.png`: Dataset size reduction stages.
  - `figure_2_caption_length_hist.png`: Caption length distribution.
  - `figure_3_common_words_bar.png`: Common token frequencies.
- **`Data/`:** Placeholder directory. **Note:** This directory is intended to hold necessary input data (like the original TSV files) and potentially output data (like processed `.parquet` or `.csv` files, and downloaded images) during the execution of the notebook. **These large data files are NOT included in this repository.**

## Process Overview

The notebook details the following key steps:

1.  **Loading:** Reads the raw Conceptual Captions TSV files.
2.  **Filtering & Cleaning:** Reduces dataset size based on resource constraints using a label subset file and normalizes caption text.
3.  **Image Acquisition:** Downloads images from URLs asynchronously and validates their integrity.
4.  **Output:** Generates final data manifests (intended to be saved in `Data/`) linking local validated image paths to cleaned captions.
5.  **Analysis:** Creates the plots found in the `figures/` directory.

## Setup & Usage

1.  **Clone Repository:** `git clone <repository-url>`
2.  **Prerequisites:**
    - Python 3.x
    - Install required libraries (refer to imports in `notebook.ipynb`, typically `pandas`, `pyarrow`, `matplotlib`, `pillow`, `aiohttp`, `aiofiles`, `tqdm`, `nest_asyncio`).
      ```bash
      pip install pandas pyarrow matplotlib pillow aiohttp aiofiles tqdm nest_asyncio notebook
      ```
    - Obtain the raw Conceptual Captions TSV files and place them in the `Data/` directory (or update the path within the notebook).
3.  **Run Notebook:** Execute the cells in `notebook.ipynb` sequentially. Be aware that the image download step (`process_dataframe`) is time-consuming.

## Data Storage Note

The large input TSV files, the downloaded images, files are **not stored** in this Git repository due to their size. The notebook is configured to read from and write to the `Data/` directory locally. Ensure you have sufficient local storage.
